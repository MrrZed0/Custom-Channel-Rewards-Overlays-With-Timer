Streamer.bot Setup
Three steps to go live. The C# helper at the bottom is optional.
1 Turn on the WebSocket

Streamer.bot → Servers/Clients → WebSocket Server. Enable it on 127.0.0.1:8080 and tick auto-start.

2 Make 4 chat Actions

Each one needs a single sub-action: Twitch/Kick → Chat → Send Message to Channel, with the message set to %rewardMessage% or %timerMessage%.

3 Add the overlay to OBS

Export the overlay, then add a Browser Source in OBS pointing at the local file, sized 1920×1080.

The overlay listens to native Twitch and Kick reward redemptions on its own and parses (5:00) out of the description itself — so for most setups you can stop after step 3. The C# helper below only matters if you want Streamer.bot to resolve avatars or pre-parse durations before broadcasting.
